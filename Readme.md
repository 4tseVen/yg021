# Digital Identity Portfolio

## Project Description

This project is a responsive personal portfolio website developed using HTML, CSS, and JavaScript.

The website showcases my:

- Personal introduction
- Educational background
- Technical skills
- Academic projects
- Contact information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Design Features

- Dark Mode design
- F-Layout structure
- Responsive design
- Mobile navigation menu
- Modern typography
- Three-color palette

## Color Palette
